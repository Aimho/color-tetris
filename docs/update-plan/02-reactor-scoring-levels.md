# 2단계: 리액터·점수·레벨

## 구현 범위

- 기존 시간제 리액터와 리액터 중 무작위 화살표 생성 제거
- 리액터 충전 전까지 발생한 체인으로 체인 파워 누적
- 체인별 파워: 1=0, 2=1, 3=2, 4=3, 5 이상=4
- 리액터 100% 도달 시 파워 구간별 곱셈 셀 보상
  - 0~1: ×2 한 개
  - 2~3: ×2 두 개
  - 4~5: ×2 한 개와 ×3 한 개
  - 6~8: ×3 두 개
  - 9 이상: ×2 한 개와 ×3 두 개
- 곱셈 셀은 최대 3개이며 임의의 비어 있는 열로 하나씩 하드드롭
- 착지 위치 주변에서 가장 큰 연결을 만드는 색상을 시스템이 선택
- 같은 삭제 단계의 곱셈은 곱하며 최대 ×6
- 최종 점수는 `기본 삭제 점수 × 체인 배수 × 특수 셀 배수`
- 레벨 상승 간격을 삭제 20칸에서 15칸으로 단축
- 최대 레벨은 두지 않되 낙하 간격은 레벨 1의 600ms에서 120ms로 완만하게 수렴
- 속도 선택은 제거하고 모든 플레이를 기존 EXPERT 배율(1.2배)로 통일
- EXPERT 배율을 적용한 실질 낙하 간격은 약 100ms를 하한으로 유지

## 테스트

- 체인 파워 경계값별 보상이 정확하다.
- 가득 찬 열은 곱셈 셀 후보에서 제외된다.
- 인접 색상 동률은 주입된 난수로 결정된다.
- ×2+×3, ×3+×3 모두 ×6 상한을 지킨다.
- 특수 제거만으로 리액터가 충전되지 않는다.
- 매우 높은 레벨에서도 낙하 간격이 120ms 아래로 내려가지 않는다.

## 롤백

점수 원장에는 `ruleVersion`을 기록한다. 새 배수 규칙을 비활성화해도 이전 시즌 기록은 유지하되 서로 비교하지 않는다.
