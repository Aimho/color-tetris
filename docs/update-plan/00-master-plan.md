# COLOR BOMB 업데이트 총괄 계획

## 목표

현재 색상 연결 퍼즐의 조작감은 유지하면서, 연쇄를 장기적으로 설계할 이유와 공정한 시즌 경쟁 구조를 추가한다. 업데이트는 게임 규칙, 진행 시스템, 랭킹, 계정 경험, 결과 화면 순서로 적용하며 각 단계는 독립적으로 되돌릴 수 있어야 한다.

## 확정 범위

1. 특수 셀: 화살표, 폭탄, 곱셈 셀
2. 리액터: 시간제 모드 제거, 누적 체인 파워 보상으로 교체
3. 모드: 연습 무제한, 랭킹 도전 하루 3회
4. 랭킹: 월간 시즌, 모바일/데스크탑 분리, TOP 50
5. 프로필: 자동 닉네임, 마이페이지, 설정
6. 결과: 자동 최고 기록 저장, 공유하기와 홈으로
7. 운영: 시즌 배지, 모바일 검증, 성능·접근성 최적화

## 제외 범위

- 프리즘 셀
- 랭킹 도전권 광고·유료 판매
- 점수·특수 셀·이어하기에 영향을 주는 결제
- 초기 앱 버전의 광고
- 테마의 실제 판매 및 보상형 광고 활성화
- iOS 출시와 Apple 로그인

## 핵심 데이터 흐름

```text
게임 엔진
  ├─ 직접 연결/체인 ──> 특수 셀 대기열 ──> 다음 조각
  ├─ 체인 파워 ──────> 리액터 100% ───> 곱셈 셀 낙하
  ├─ 진행 스냅샷 ────> 기기 저장소 ─────> 계속하기
  └─ 종료 기록 ──────> 검증 함수 ───────> 시즌 랭킹
                                           └─ 마이페이지
```

## 외부 의존성

- Firebase Authentication: 익명 사용자와 추후 소셜 계정 연결
- Cloud Firestore: 시즌 기록, 닉네임, 프로필 통계
- Cloud Functions: 랭킹 도전권 및 점수 원장 검증
- Firebase App Check: 웹 reCAPTCHA Enterprise, Android Play Integrity
- Firebase Remote Config: 일일 도전 횟수와 기능 롤백 스위치
- Firebase Analytics/Crashlytics: 앱 출시 후 최소 진단 정보

Cloud Functions 배포에는 Blaze 요금제가 필요하다. 예산 알림을 설정하고 무료 할당량을 우선 사용한다.

## 위험과 대응

- Firebase 장애: 연습 모드는 계속 제공하고 랭킹 시작만 잠근다.
- 사용자 증가: 시즌·플랫폼별 상위 50 문서와 개인 최고 문서를 분리해 읽기량을 제한한다.
- 규칙 오류: `ruleVersion`으로 기록을 격리하고 Remote Config로 랭킹 시작을 중지할 수 있게 한다.
- 광고 수요 부족: 초기에는 광고 기능 자체를 노출하지 않는다.

## 완료 기준

- 각 단계의 단위 테스트와 전체 빌드가 통과한다.
- 375px 모바일과 데스크탑 키보드 환경에서 주요 흐름을 검증한다.
- 게임 중 백그라운드 전환, 오프라인, 서버 오류가 플레이 상태를 손상시키지 않는다.
- 점수 계산과 랭킹 기록을 클라이언트에서 임의 변경할 수 없다.
