# 7단계: 모바일 검증·최적화·출시 준비

## 기능 검증

- 375px, 390px, 태블릿, 데스크탑에서 홈·게임·랭킹·설정·마이페이지 확인
- 터치 드래그, 탭 회전, 하드드롭 제스처와 키보드 입력 확인
- Safari와 Android WebView의 오디오 잠금 해제 확인
- 확대, 텍스트 선택, 길게 누르기 메뉴, 오버스크롤을 게임 캔버스에서 차단
- 백그라운드 저장·복귀, 오프라인 전환, 서버 장애 확인

## 성능

- 게임 루프에서 임시 배열과 전체 보드 스캔 횟수 측정
- 파편 수 상한과 저사양 파티클 설정 적용
- 애니메이션은 transform과 opacity 중심으로 유지
- 모션 감소와 화면 흔들림 끔 설정 검증
- Firebase 읽기 수, 함수 호출 수, App Check 실패율 모니터링

## 배포 안전장치

- 기능별 Remote Config 스위치
- 규칙 변경 시 앱 버전과 `ruleVersion` 동시 증가
- Firebase 예산 알림 설정
- Firestore 인덱스와 보안 규칙 에뮬레이터 테스트
- 웹 배포 후 캐시 버전과 첫 화면 빌드 번호 확인
- 앱은 내부 테스트, 비공개 테스트, 프로덕션 순으로 승격

## 광고·보상 후속 조건

- 초기 앱 버전에는 광고 없음
- 충분한 꾸미기 콘텐츠가 생긴 뒤 사용자 선택형 보상 광고만 활성화
- 보상: 스파크, 폭발·파편·리액터 연출 체험권, 배경·보드·사운드 테마 체험권
- 일일 미션 2배와 플레이 분석·리플레이 보상은 제공하지 않음
- 광고나 결제로 랭킹 횟수, 점수, 특수 셀, 이어하기를 제공하지 않음

## 출시 완료 기준

- 전체 자동 테스트와 프로덕션 빌드 통과
- 모바일 실기기에서 20분 이상 플레이하며 입력·오디오·발열 확인
- 오류 추적, 개인정보처리방침, 지원·계정 삭제 페이지 준비
- 랭킹 검증 실패 시 연습 모드로 안전하게 전환
