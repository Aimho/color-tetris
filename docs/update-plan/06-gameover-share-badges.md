# 6단계: 게임오버·공유·시즌 배지

## 구현 상태

코드 구현과 자동 테스트 완료.

- 랭킹 게임 종료 시 익명 UID 기록을 자동 제출하고 첫 기록·신기록·기존 기록·오프라인 상태를 구분한다.
- 실패한 네트워크 제출은 기기에 한 건 보관하고 다음 랭킹 서버 연결 때 재시도한다.
- 게임오버 화면은 점수·레벨·시즌 최고·현재 순위와 `공유하기`, `홈으로`만 표시한다.
- 종료 시즌 배지는 마지막 랭킹 제출 유예 24시간이 지난 뒤 마이페이지를 불러올 때 서버가 미처리 시즌을 한 번에 하나씩 선점·확정해 중복 읽기와 전체 사용자 스캔 비용을 피한다.

## 게임오버

- 이름 입력과 기록 저장 확인 제거
- 서버가 시즌·플랫폼 최고 기록을 자동 갱신
- 버튼은 `공유하기`, `홈으로`만 제공
- 일반: `멋진 연쇄였어요!`
- 신기록: `기록을 제대로 터뜨렸어요! 🎉`
- 첫 기록: `첫 기록이 생겼어요!`
- 오프라인: `기록은 잘 챙겨뒀어요!`
- 점수, 레벨, 시즌 최고와 차이 또는 현재 순위를 함께 표시

## 공유

- Web Share API를 우선 사용하고 미지원 환경에서는 링크 복사
- 점수, 플랫폼 시즌 순위, 도전 문구, 게임 링크 포함
- 공유 카드용 OG 이미지와 제목·설명을 COLOR BOMB 브랜드로 통일
- 개인 식별자나 실행 토큰은 공유하지 않음

## 시즌 배지

- 시즌 종료 시 TOP 1, TOP 10, TOP 50 배지 확정
- 개인 시즌 최고 기록 배지 제공
- 배지는 프로필 장식만 하며 게임 능력에 영향을 주지 않음

## 테스트

- 첫 기록, 일반 기록, 신기록, 오프라인 문구 분기
- 공유 취소를 오류로 표시하지 않음
- 클립보드 권한 실패 시 수동 복사 안내
- 시즌 종료 작업을 재실행해도 배지가 중복 생성되지 않음
