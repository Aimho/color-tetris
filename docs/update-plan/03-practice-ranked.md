# 3단계: 연습·랭킹 모드와 도전 횟수

## 구현 범위

- 홈에서 `연습하기`와 `랭킹 도전`을 분리
- 연습 모드는 오프라인 무제한이며 시즌 랭킹에 반영하지 않음
- 랭킹 도전은 KST 기준 하루 3회
- 랭킹 게임 시작 버튼을 누르면 서버가 즉시 도전권을 차감하고 1회용 실행 토큰 발급
- 게임 화면에 `PRACTICE` 또는 `RANKED` 표시
- 백그라운드 이동 시 즉시 일시정지하고 기기에 상태 저장
- 복귀·새로고침·앱 재실행 시 동일한 진행 상태와 `계속하기` 팝업 복구
- 저장 게임을 포기해도 사용한 랭킹 도전권은 복원하지 않음
- 앱 종료 직전, `visibilitychange`, `pagehide`에 스냅샷 저장

## 장애 대응

- 서버에 연결할 수 없으면 연습 모드는 허용하고 랭킹 시작은 비활성화
- 진행 중 랭킹 게임은 로컬 스냅샷과 실행 토큰으로 복원
- Remote Config로 일일 횟수를 변경하거나 제한을 즉시 해제

## 테스트

- KST 자정에 횟수가 초기화된다.
- 시작 버튼 연속 탭으로 도전권이 중복 차감되지 않는다.
- 백그라운드 동안 낙하·리액터·음악 시간이 진행되지 않는다.
- 오래된 실행 토큰과 이미 종료된 실행 토큰은 재사용되지 않는다.
- 연습 기록은 개인 누적 통계에 포함되지만 시즌 랭킹에는 제출되지 않는다.
