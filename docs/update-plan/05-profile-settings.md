# 5단계: 닉네임·마이페이지·설정

## 구현 상태

코드 구현과 로컬 반응형 검증 완료. 랭킹은 익명 UID로 즉시 참여하며 Google 계정 연결은 마이페이지에서 선택적으로 제공한다.

- 서버가 웃긴 기본 닉네임을 원자적으로 예약하고 직접 변경 후 24시간 제한을 검증한다.
- 마이페이지에서 시즌별 모바일·데스크탑 기록, 로컬 누적 통계, 시즌 배지와 테마를 표시한다.
- 설정은 사운드, 진동, 흔들림, 파티클, 모션 감소, 색상 보조와 모바일 감도를 즉시 저장한다.
- 오프라인에서는 마지막 동기화 시각과 로컬 기록을 유지한다.
- 개인정보 처리방침, 고객 지원, 계정 삭제 요청과 제한된 로컬 데이터 초기화 경로를 제공한다.

## 닉네임

- 첫 실행 시 `웃긴 형용사 + COLOR BOMB 명사 + 세 자리 숫자` 형식 자동 배정
- 서버가 전역 닉네임을 원자적으로 예약하고 충돌 시 숫자를 다시 선택
- 자동 닉네임은 즉시 한 번 변경 가능
- 직접 변경한 뒤에는 24시간 후 다시 변경 가능
- 익명 UID에 연결하고 소셜 계정 연결 후에도 유지

## 마이페이지

- 프로필과 소셜 연결 상태
- 모바일/데스크탑 현재 시즌 순위, 최고 점수, 최고 레벨
- 전체 게임 수, 역대 최고 기록·레벨·체인
- 누적 삭제, 폭탄 획득, 리액터 사용, 최고 체인 파워
- 오프라인에는 로컬 통계와 마지막 동기화 시각 표시
- 시즌 TOP 1·10·50 및 개인 최고 기록 배지

## 설정

- 독립된 전체 화면 페이지
- BGM, 효과음, 모바일 진동
- 화면 흔들림: 끔/낮음/보통
- 파티클: 낮음/보통/높음
- 모션 감소: 기기 설정 연동 및 수동 활성화
- 색상 구분 보조: 셀 모서리 패턴
- 모바일 드래그 감도: 낮음/보통/높음
- 모바일·데스크탑 조작 안내
- 로컬 데이터 초기화, 개인정보·지원·계정 삭제 링크, 앱 버전
- 설정 변경 즉시 저장하고 가능한 항목은 짧게 미리보기

## 테스트

- 닉네임 충돌과 24시간 제한을 서버 시간이 검증한다.
- 익명 계정 연결 후 기록과 닉네임이 유지된다.
- 설정이 새 세션과 앱 재실행 후 유지된다.
- 모바일 전용 설정은 데스크탑에서 숨긴다.
- 모든 조작 요소가 키보드와 40px 이상 터치 영역을 지원한다.
