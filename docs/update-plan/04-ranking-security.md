# 4단계: 서버 검증과 시즌 랭킹

## 구현 범위

- 매월 KST 기준 새 시즌 생성, 이전 시즌 기록 보존
- 모바일과 데스크탑 랭킹 분리
  - 네이티브 앱 또는 터치 우선 입력: 모바일
  - 키보드 우선 웹: 데스크탑
  - 플랫폼은 게임 시작 시 고정
- 각 플랫폼 TOP 50과 사용자의 시즌 최고 기록 표시
- 정렬: 점수 내림차순, 레벨 내림차순, 달성 시각 오름차순
- 최고 기록은 자동 제출하며 더 높은 기록만 갱신
- 점수 원장에 시즌, 규칙 버전, 플랫폼, 플레이 시간, 직접·특수 삭제, 최대 체인, 리액터 및 배수 정보를 포함
- Cloud Function이 실행 토큰과 원장을 검증한 뒤 Firestore 기록
- App Check와 제출 속도 제한 적용
- 오프라인 종료 기록은 대기열에 저장 후 연결 시 제출

## 화면

- 현재 시즌 종료까지 남은 시간
- MOBILE/DESKTOP 탭
- 순위 밖에서도 보이는 MY BEST
- TOP 50 목록과 내 행 강조
- 로딩 중 목록 형태를 유지하는 스켈레톤

## 테스트

- 동점 정렬 규칙이 결정적이다.
- 직접 Firestore 쓰기는 거부된다.
- 다른 플랫폼·시즌·규칙 버전 토큰은 거부된다.
- 같은 종료 기록을 여러 번 보내도 한 번만 처리된다.
- 오프라인 대기열은 성공한 항목만 제거한다.
