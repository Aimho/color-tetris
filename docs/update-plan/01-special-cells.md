# 1단계: 게임 규칙과 특수 셀

## 구현 범위

- 기존 무작위 10% 화살표와 16조각 보정 생성 제거
- 직접 색상 연결의 두 번째 연쇄에 도달하면 화살표 1개 예약
- 한 번에 9칸 이상 직접 연결하면 폭탄 1개 예약
- 화살표와 폭탄은 각각 최대 1개만 대기
- 다음 조각에는 특수 셀을 최대 1개만 배치
- 배치 우선순위는 폭탄, 화살표 순서
- 화살표 방향은 무작위이며 조각 회전에 맞춰 함께 회전
- 폭탄은 발동 셀 중심 3×3 영역 제거
- 폭탄과 화살표는 서로 맞으면 약 0.1초 간격으로 연쇄 발동
- 특수 효과로 제거한 셀은 점수와 레벨에는 포함하지만 리액터 충전과 폭탄 획득 판정에서는 제외

## 표현

- 셀 중앙 기호는 운영체제별 이모지 대신 동일한 캔버스 벡터 아이콘으로 그린다.
- 화살표는 방향이 즉시 읽히는 굵은 화살표, 폭탄은 원형 본체와 심지로 표현한다.
- 폭탄 발동은 중심 확장 링과 기존 파편 효과를 결합한다.
- `prefers-reduced-motion`에서는 확장 이동을 줄이고 짧은 명도 변화만 사용한다.

## 테스트

- CHAIN 1에서는 화살표가 생기지 않고 CHAIN 2 이상에서 1개만 생긴다.
- 직접 연결 8칸은 폭탄을 주지 않고 9칸은 1개를 준다.
- 같은 판에서 두 보상을 얻으면 폭탄이 먼저, 화살표가 다음 조각에 배치된다.
- 보드 가장자리 폭탄은 보드 밖을 참조하지 않는다.
- 폭탄이 화살표·폭탄을 맞히면 각 특수 셀이 한 번만 발동한다.
- O 조각 회전 시 화살표 방향과 셀 색상 배치가 함께 회전한다.

## 롤백

특수 셀 생성과 해결 로직을 별도 모듈에 유지한다. 문제가 생기면 보상 생성을 끄고 일반 색상 셀만 생성하도록 전환할 수 있다.
