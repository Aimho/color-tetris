# COLOR BOMB Play Console 프로덕션 제출 문안

최종 갱신: 2026-10-02

## 프로덕션 액세스 신청

### 비공개 테스트에서 사용한 기능

테스터들은 연습 모드와 랭킹 도전, 터치·드래그 조작, 게임 일시정지와 백그라운드 복귀, 닉네임 및 Google 계정 연결, 일일·주간 미션, SPARK 상점, 테마 선택, 랭크 에너지 자동 충전과 보상형 광고 충전을 사용했습니다. 실제 출시 후에도 사용자가 이용할 핵심 흐름과 같은 방식으로 테스트했습니다.

### 피드백 수집 및 반영

테스터 피드백과 오류 추적을 통해 구형 Android WebView에서 일부 그래픽과 음악 API가 지원되지 않는 문제, 이전 랭킹 탭과 UI가 노출되는 문제, 홈 버튼 위계와 마이페이지 정보 밀도 문제를 확인했습니다. Canvas 경로, 배열 탐색, 상태 복제와 UUID 생성에 구형 WebView 호환 처리를 추가했고, 홈을 랭킹·미션·상점 중심으로 재정리했습니다. 랭크 에너지는 최대 3개, 30분당 1개 자동 충전으로 조정하고 광고 보상은 서버 확인 후 한 번만 지급하도록 구성했습니다.

### 게임의 차별점

COLOR BOMB는 테트로미노를 쌓되 줄 완성 대신 같은 색 블록 6개 이상을 연결해 폭발시키는 퍼즐 액션 게임입니다. 낙하 이후 중력으로 새로운 색 연결과 연쇄가 발생하며, 방향 화살표·리액터·배수 블록을 이용해 다음 폭발을 설계하는 전략성이 핵심입니다. 연습은 제한 없이 제공하고 랭킹 플레이는 서버가 조각 순서와 배치 기록을 검증해 공정성을 유지합니다.

### 프로덕션 준비 완료 판단 근거

핵심 게임 로직, 서버 검증, Firestore 보안 규칙과 반응형 사용자 흐름에 자동 테스트를 적용했습니다. Android 9 이상과 Android 16 대상 설정을 사용하며, Firebase App Check·AdMob SSV·Sentry 오류 추적을 구성했습니다. 광고 실패나 네트워크 단절 시에도 연습 모드와 자동 에너지 충전은 유지되며, 중복 요청은 서버에서 한 번만 처리합니다. 비공개 테스트에서 확인된 주요 호환성과 UI 문제를 수정한 뒤 프로덕션 출시 후보를 준비했습니다.

## 스토어 등록정보 초안

### 앱 이름

COLOR BOMB

### 짧은 설명

같은 색 6개를 연결하고 연쇄 폭발을 설계하는 퍼즐 액션 게임

### 전체 설명

테트로미노를 쌓고, 같은 색 블록 6개 이상을 연결해 폭발시키세요.

COLOR BOMB는 줄을 완성하는 대신 색 연결과 낙하 연쇄를 만드는 퍼즐 액션 게임입니다. 블록이 사라진 자리에 중력이 적용되면 새로운 연결이 생기고, 연쇄가 커질수록 점수와 연출도 강해집니다.

주요 특징

- 같은 색 6개 이상을 연결하는 직관적인 폭발 규칙
- 낙하와 연쇄를 미리 설계하는 전략적인 보드 플레이
- 행과 열을 제거하고 연속 발동하는 방향 화살표
- 충전 후 자동으로 폭발을 강화하는 리액터
- 서버 검증을 사용하는 월간 Android 앱 랭킹
- 매일·매주 갱신되는 미션과 SPARK 보상
- SPARK로 해금하는 그래픽 테마와 꾸미기 아이템
- 제한 없이 즐기는 연습 모드

짧게 시작해도 좋고, 한 번의 거대한 연쇄를 위해 오래 설계해도 좋습니다. 나만의 폭발 루트를 만들고 시즌 최고 기록에 도전하세요.

### 버전 1.0.0 출시 노트

- COLOR BOMB 첫 정식 버전을 출시합니다.
- 랭킹, 일일·주간 미션, SPARK 상점과 그래픽 테마를 추가했습니다.
- 랭크 에너지 자동 충전과 보상형 광고 충전을 적용했습니다.
- 구형 Android WebView의 그래픽·음악·게임 상태 호환성을 개선했습니다.
- 홈, 도움말과 마이페이지 UI를 더 보기 쉽게 정리했습니다.

### 버전 1.0.3 출시 노트

- 7일 출석 보상과 연속 출석 SPARK를 추가했습니다.
- 게임 결과를 점수 카드와 설치 링크로 더 쉽게 공유할 수 있습니다.
- 앱 이용 흐름을 개선하기 위한 익명 분석을 추가했습니다.
- 출석, 상점, 공유 흐름의 안정성을 개선했습니다.

## 심사자 안내

별도 회원가입 없이 앱을 실행하면 Firebase 익명 계정으로 연습 모드와 대부분의 기능을 확인할 수 있습니다. 랭킹 도전도 Google 계정 연결을 강제하지 않습니다. Google 계정 연결은 마이페이지에서 사용자가 선택하는 기능입니다. 보상형 광고는 랭크 에너지가 최대치보다 적을 때 홈에서 선택할 수 있으며, 광고를 이용하지 않아도 연습 모드와 30분당 1개의 자동 충전을 사용할 수 있습니다.
