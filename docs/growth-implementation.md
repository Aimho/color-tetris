# 출시 후 성장 기능 — 작업 브랜치

기준 버전: v1.0.2. 작업 브랜치: codex/analytics-share-attendance.

## 구현

- Firebase Analytics 네이티브 이벤트: 앱 실행, 화면, 도움말, 게임 시작/종료, 광고 요청/완료/실패, 출석, 구매/장착, 공유. 사용자 ID·닉네임은 보내지 않으며 허용된 매개변수만 전송한다.
- 결과 공유: 점수 이미지, 설치 링크, game_share / organic / ranking_challenge UTM. 파일 공유 미지원 시 텍스트, 공유 미지원 시 클립보드로 대체한다.
- 서버 기준 7일 출석: 한국 시간 자정, 10/15/20/25/30/40/75 SPARK, 하루 1회. 결석 또는 7일 완료 다음 날 새 주기. 계정 삭제 시 기록 삭제.

## 배포 전 남은 외부 확인

검증: 단위 테스트 164개 통과, 환경 의존 7개 건너뜀. 데스크톱/Pixel 브라우저 테스트 12개와 375px/1280px 출석 화면 테스트 1개 통과. Vite 빌드 및 Android/iOS Capacitor 동기화 통과. 보안·구조 검토에서 발견한 자정 이전 지연 요청의 중복 지급 가능성을 수정하고 회귀 테스트를 추가했다.

- claimDailyAttendance 함수와 갱신된 getOrCreatePlayerProfile을 서버에 배포한다.
- 개인정보처리방침을 호스팅에 반영하고 Play 데이터 보안의 앱 활동/분석 항목을 확인한다.
- Firebase Analytics 연결 상태 및 실제 기기 DebugView 이벤트를 확인한다.
- 업데이트 AAB는 새 versionCode로 빌드하고 출석 중복 수령, 자정 경계, 공유 대상 앱, 광고 복귀를 실기기로 확인한다.
- 현재 출시 버전과 태그는 보존하며 이 브랜치는 아직 출시되지 않았다.
