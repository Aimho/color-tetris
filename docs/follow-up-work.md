# 후속 작업

최종 갱신: 2026-07-26

## 우선순위 1: 시즌 결과 넛징

- 시즌 종료와 제출 유예 24시간이 지난 뒤 홈에 `지난 시즌 결과가 도착했어요!` 배너를 한 번 표시한다.
- 배너의 `결과 보기`를 누르면 마이페이지를 열고 미처리 시즌 배지를 확정한다.
- 확인 전에는 마이페이지 버튼에 작은 알림 점을 표시한다.
- 해당 시즌 결과를 확인하면 배너와 알림 점을 다시 표시하지 않는다.
- 배지가 없는 사용자에게도 시즌 최고 점수와 최종 결과를 보여준다.
- 초기 버전에서는 OS 푸시 알림을 사용하지 않는다.

## 우선순위 2: 7단계 모바일 검증과 최적화

- 375px·390px 모바일, 태블릿과 데스크탑에서 홈·게임·게임오버·랭킹·마이페이지·설정을 확인한다.
- 수동 일시정지, 백그라운드 복귀, 게임 방법 열기·닫기와 홈 이탈 흐름을 실기기에서 검증한다.
- Android WebView와 iOS Safari/WKWebView에서 오디오 잠금 해제, 확대·선택·롱프레스 차단을 확인한다.
- 게임 루프의 보드 스캔, 배열 생성, 파편 수와 저사양 설정의 성능을 측정한다.
