## 완료: 시즌 결과 넛징

- 시즌 종료와 제출 유예 24시간이 지난 뒤 홈에 `지난 시즌 결과가 도착했어요!` 배너를 한 번 표시한다.
- 배너의 `결과 보기`를 누르면 마이페이지를 열고 미처리 시즌 배지를 확정한다.
- 확인 전에는 마이페이지 버튼에 작은 알림 점을 표시한다.
- 해당 시즌 결과를 확인하면 배너와 알림 점을 다시 표시하지 않는다.
- 배지가 없는 사용자에게도 시즌 최고 점수와 최종 결과를 보여준다.
- 초기 버전에서는 OS 푸시 알림을 사용하지 않는다.
