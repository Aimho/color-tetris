## 배포 후 확인이 필요한 항목

- 실제 Firebase App Check가 적용된 모바일 Safari와 Android Chrome에서 익명 랭킹 1회 완료
- 동일 익명 UID의 기록이 웹 TOP 50 및 내 기록에 함께 표시되는지 확인
- 네이티브 앱 출시 후 Android/iOS App Check ID가 모바일 버킷으로 분류되는지 확인
- 네트워크를 끊은 상태로 랭킹 종료 후 재접속했을 때 대기 기록이 자동 제출되는지 확인
- Firestore 규칙 테스트는 Java 21 환경에서 별도 실행
